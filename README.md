# Palash Parate - GitHub Pages Website

Files:
- index.html
- privacy-policy.html
- style.css

## Before publishing
Replace `your-email@example.com` in:
- index.html
- privacy-policy.html

Optionally update the Apps & Projects section with your actual Google Play apps.

## Publish on GitHub Pages
1. Create or open your GitHub repository.
2. Upload these files to the root of the repository.
3. Commit the files.
4. Go to Settings → Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select your main branch and `/ (root)`.
7. Save.

Your website will usually be available at:
https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/

If the repository is named:
YOUR-GITHUB-USERNAME.github.io

then the site will be:
https://YOUR-GITHUB-USERNAME.github.io/
