# Palash Parate — Portfolio

Static portfolio website optimized for GitHub Pages.

## Deploy
1. Replace the files in the root of `palashparate009.github.io` with these files.
2. Make sure `index.html`, `style.css`, `script.js`, and the `assets` folder are committed to the branch used by GitHub Pages.
3. Open https://palashparate009.github.io after deployment.

No build tools, npm packages, or frameworks are required.
